# Objective
A clean and modern pastel-themed web calculator built with Python Flask, HTML, CSS, and JavaScript. The application performs basic arithmetic operations with input validation, responsive design, and a smooth calculation success experience.

# Technologies Used
Technology	Purpose
Python	Backend programming
Flask	Web server and API
HTML5	Page structure
CSS3	Styling and animations
JavaScript	User interaction and API communication

# Installation
1. Clone the Repository
git clone https://github.com/your-username/calculator-project.git

Move into the project directory:

cd calculator-project
2. Install Python

Make sure Python is installed on your system.

Check the installed version:

python --version

Python 3.9+ is recommended.

3. Install Dependencies

Install Flask using:

python -m pip install -r requirements.txt

Or install Flask directly:

python -m pip install Flask

4. Run the code
python app.py
